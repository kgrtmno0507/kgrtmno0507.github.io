itpass-uploader について

「itpass-uploader」は、このチャンネルの運営者が自分で作った動画を、自分の YouTube チャンネルにアップロードするためだけの内部ツールです。YouTube Data API を使い、動画は非公開でアップロードされ、運営者が内容を確認してから公開します。運営者以外の人が使うことはありません。

itpass-uploader is an internal tool that uploads videos created by this channel's owner to the owner's own YouTube channel via the YouTube Data API. Videos are uploaded as private and published manually after review. It is not offered to or used by anyone else.
