プライバシーポリシー

対象：itpass-uploader（1日1語ITパスポート｜ずんだもん解説 の動画アップロード用ツール）
制定日：2026年9月23日

1. 取得する情報

本ツールは、運営者本人の Google アカウントで YouTube への動画アップロード権限（youtube.upload）の許可を受けます。取得するのは、アップロードに必要なアクセス トークンのみです。運営者以外の利用者の個人情報は取得しません。

2. 利用目的

運営者が作成した動画を、運営者の YouTube チャンネルにアップロードするためだけに使います。

3. 保存と管理

トークンは運営者の GitHub リポジトリの暗号化されたシークレットにのみ保存し、第三者に提供・販売しません。本ツールによる Google ユーザーデータの利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

4. 取り消しと削除

許可は Google アカウントのサードパーティ アクセス からいつでも取り消せます。取り消すと、本ツールはアップロードできなくなります。保存しているトークンは、取り消し後または削除の依頼を受けてから 7 日以内に削除します。削除の依頼は下のお問い合わせ先へ。

5. YouTube API Services

本ツールは YouTube API Services を使用します。本ツールを使うことで YouTube 利用規約 に同意したことになります。Google による情報の取り扱いは Google プライバシー ポリシー をご確認ください。

6. Cookie など

本ツールおよびこのウェブサイトは、Cookie やアクセス解析を使わず、閲覧者の情報を集めません。

7. お問い合わせ

zundamon408@gmail.com

itpass-uploader only requests the youtube.upload scope for the channel owner's own Google account, uses it solely to upload the owner's videos to the owner's channel, stores the token only in encrypted GitHub secrets, and never shares or sells it. Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions; stored tokens are deleted within 7 days after revocation or upon request to the contact address.
